## What Sheaf is

Sheaf is a notes app for the GNOME desktop, written in Rust with [GPUI](https://www.gpui.rs),
the UI framework of the Zed editor. In GNOME it is simply called **Notes**. It is free software
under the GPL-3.0-or-later.

<CardGrid>
  <Card title="A gallery of cards" icon="seti:image">
    Each note is a card with a miniature of its first lines, grouped by date. Folders, tags,
    pinned notes, smart folders and a list view.
  </Card>
  <Card title="Edit in place" icon="pencil">
    Checklists, tables, images and links between notes, a format bar and a slash menu. Notes
    save themselves a moment after you stop typing.
  </Card>
  <Card title="Search in milliseconds" icon="magnifier">
    Forgives typos, understands `#tag`, `folder:`, `has:checklist` and more. About 6 ms (p95)
    with 10,000 notes.
  </Card>
  <Card title="Just Markdown files" icon="document">
    One `.md` file per note, subfolders as folders. Sync them with any tool and open them in
    any editor. No database, no lock-in.
  </Card>
</CardGrid>

## Also included

- **Quick Note** window on a global shortcut (Ctrl+Shift+N).
- **Notes in the GNOME overview** through a search provider: press Super and type.
- **Recently Deleted** keeps removed notes for 30 days.
- **Export** to Markdown and PDF, and printing.
- **A command line** with JSON output for scripts and AI agents.
- **Ten languages**: English, German, Spanish, French, Brazilian Portuguese, Italian, Polish,
  Russian, Simplified Chinese and Japanese.
