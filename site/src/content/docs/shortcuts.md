---
title: Keyboard shortcuts
description: All keyboard shortcuts of Sheaf, the GNOME notes app - new note, search, command palette, pin, Quick Note and the editor keys.
---

Press **Ctrl+?** in the app to see this list.

## App

| Keys | Action |
|---|---|
| Ctrl+N | New note |
| Ctrl+F, or just start typing | Search |
| Ctrl+K | Command palette |
| Esc, Ctrl+W | Back to the gallery |
| Ctrl+P | Pin or unpin the note |
| Ctrl+Shift+N | Quick Note |
| Ctrl+, | Settings |
| Ctrl+? | Keyboard shortcuts |
| Ctrl+Q | Quit |

## In a note

| Keys | Action |
|---|---|
| Ctrl+B | Bold |
| Ctrl+I | Italic |
| Ctrl+F | Find in the note |
| Ctrl+. | Fold or unfold the section |
| Ctrl+Shift+K | Insert a link (Ctrl+K is the command palette) |
| `/` at the start of a line | Block menu |
| `/template` | Insert a template |
| `[[` | Link to another note |
